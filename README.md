# My React Blog

This is a simple blog built with React. It is deployed automatically to GitHub Pages on every push to the main branch.

## Features

- Built with React
- Deployed to GitHub Pages
- Automatic deployment on every push

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/Primolo/my-react-blog.git
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm start
   ```

4. Build the app for production:
   ```bash
   npm run build
   ```

5. Run tests:
   ```bash
   npm test
   ```
